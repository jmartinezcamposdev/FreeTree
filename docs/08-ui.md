## Layout

```
┌ TabBar: [repoA ×] [repoB ×] [+] ───────────────────────────────────────────┐
│ Toolbar: [⟳] [Pull] [Push]  branch ↑2 ↓1  │ Query: [__________] [Refs ▾]  │
├──────────────────────────────────────────────┬─────────────────────────────┤
│ GraphList                                    │ DetailPane                  │
│  ○ Changes (3)                               │ CommitPanel | ChangesPanel  │
│  ● [main][origin/main] subject  author date  │ file list                   │
│  ...                                         │ DiffView                    │
└──────────────────────────────────────────────┴─────────────────────────────┘
```

Fixed proportions in the MVP; draggable divider is post-MVP. Empty state: “Open repository…” with
`JFileChooser` in directory mode or the platform `FileDialog`.

## GraphList

- `LazyColumn` with `items(count = rowCount + 1)`; item 0 is “Changes”, commit row `r` is item
  `r + 1`.
- Fixed row height; each row draws its own `Canvas` from `snapshot.segments(row)`.
- Cell width = `min(maxLanes, MAX_VISIBLE_LANES) * LANE_WIDTH`; clip overflow and keep the selected
  commit's lane visible.
- Node: filled circle; merge = ring; HEAD = halo; selected row = background.
- Edges: lines or cubic curves; arrows on merge `OUT`s.
- Reuse `Path`/`Paint` with `drawWithCache`/`remember`; no per-segment allocations while scrolling.
- Chips: local/remote/tag colors, HEAD highlighted; max 3 + “+N” tooltip. Look up labels by hash;
  add HEAD from `head.commit`.
- Progress indicator while `complete == false`.
- Keyboard: ↑/↓, PageUp/PageDown, Home/End, Ctrl+R, Ctrl+W, Ctrl+Tab.

## Panels

- **CommitPanel:** hash, parents (clickable), author, date, message, merge note, file list
  (A/M/D/R), selected diff.
- **ChangesPanel:**
  - Conflicts: read-only, no stage/discard.
  - Staged: per file “Discard staged” (index only; disk untouched). This is the unstage action.
  - Unstaged: per file “Discard unstaged changes” (tracked restore or untracked delete; changes
    disk) and “Stage”.
  - A file in both sections shows both discard actions; staged keeps the worktree, unstaged keeps
    the index.
  - Confirmation only for unstaged; it states exactly what is lost on disk.
  - Multiline message field; Commit disabled without message or staged files.
  - Optional Stage all / Unstage all.
- **DiffView:** unified diff parsed into `DiffLine`; `LazyColumn`, monospace, old/new line numbers,
  per-line backgrounds. Binary → “Binary file”; truncated → notice + “load full”. Diff text is
  selectable/copyable; copied text excludes the line-number gutter and the `+`/`-`/space markers.
  The right-click menu offers Copy (selection) and Copy all (every loaded line, including off-screen
  rows, straight from the diff model). No syntax highlighting in MVP.
- **Messages:** every `GitResult.Failure` shows the original `stderr`, selectable/copyable. Never
  swallow an error.

## GraphStyle.kt

All visual constants live here. Starting values:

| Constant | Value |
|---|---|

| `LANE_WIDTH` | `16.dp` |
| `NODE_RADIUS` | `4.dp` |
| `STROKE_WIDTH` | `1.5.dp` |

| `ARROW_SIZE` | `6.dp` |
| `ARROW_TOWARD_PARENT` | `true` |
| `DIFF_ADD_BG` | soft green |
| `DIFF_DEL_BG` | soft red |
| `DIFF_MONO_SIZE` | `12.sp` |

Define lane palettes (light/dark), chip colors, diff colors, typography, and spacing here. Dark is
the default; follow the system theme when available. No visual magic numbers elsewhere.
