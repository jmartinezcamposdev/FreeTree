# Decisions

| Date | ID | Decision | Reason | Alternatives |
|---|---|---|---|---|
| 2026-10-29 | D2 | Split the project into `core` (pure Kotlin/JVM) and `app` (Compose Desktop). | Enforces the no-Compose boundary and enables test fixtures. | Single module. |
| 2026-10-29 | D12 | Use Java 25 with `jvmToolchain(25)` for `core` and `app`; point the Compose application's `javaHome` at the same toolchain. | The spec requires Java 25. Compose `:app:run` otherwise uses the Gradle daemon JVM (Java 21) and fails with `UnsupportedClassVersionError`. No fallback JDK was needed. | Downgrade the JDK or leave the run task on the daemon JVM. |
| 2026-10-29 | D13 | Phase 0 contracts are compiling declarations. `SessionManager` constructor dependencies, `RepoSession`, `LaneLayoutEngine`, `GraphSnapshot` members, and the query functions are `TODO` stubs. | Phase 0 only defines the API surface; implementations belong to Phases 1–2. | Implement graph/query/session logic early (out of scope). |
| 2026-10-29 | D14 | Pin `kotlinx-serialization-json` to `1.12.0`. | Current stable release compatible with Kotlin 2.4.21 and required by `TabState`. | `1.11.0` or defer serialization. |
| 2026-10-29 | D15 | Use the catalog's `compose-material3` (`1.12.0-alpha03`) instead of the Compose plugin's deprecated `compose.material3` accessor. | Keeps the documented Material 3 baseline; the plugin accessor resolves 1.9.0. | `compose.material3` from the plugin. |
| 2026-10-29 | D16 | Implement the repository watcher with the JDK `WatchService` instead of adding `io.methvin:directory-watcher`. | Meets the documented watch paths, exclusions, debounce, and failure reporting with no new dependency; the bootstrap only permitted that dependency, it did not require it. | Add `io.methvin:directory-watcher`. |
| 2026-10-29 | D17 | Extend the session contracts for Phase 1: injectable `SessionManager` factories/scope/dispatchers/persistence; `RepoSession` exposes `SessionPhase`, `StateFlow<RepoUiState>`, query/selection operations, and write methods returning `Job`; add `SessionPersistence`, `PersistedSessionState`, `JsonSessionPersistence`, and `InMemorySessionPersistence`. | Required for deterministic T1–T7 tests, late-result/cancellation control, and Phase 2 UI wiring; the documented `tabs`/`activeId`/`activeSession`/`openRepo`/`closeTab`/`activate` surface is unchanged. | Keep the Phase 0 no-arg stubs and test through real I/O only. |
| 2026-10-29 | D18 | Persist `TabState` and the active tab as JSON with an atomic temporary-file replace, synchronously, at the platform path from `07-sessions.md`; tests inject an in-memory store. | Simple, durable, and matches the documented persistence format/path without new dependencies. | Background/debounced persistence or a database. |
| 2026-10-29 | D19 | QA acceptance tests use real `git` commands as independent oracles; performance data comes from `SyntheticDagGenerator` (50k) and `PerfRepoBuilder` (200k via `git fast-import`, cached under `build/perf-repo`). | Verifies the backend independently of its own parsers and keeps the normal test suite offline and fast. | In-memory-only acceptance or checking in a 200k repo. |
| 2026-10-29 | D20 | Add `RepoSession.openDiff(target, unlimited = false)` for the UI “load full” action; keep conflict exclusion on stage/unstage as well as discard, and defer reopening a path whose tab is still draining. | Enables truncated-diff recovery and preserves T1/T7 coherence during close/drain. | Separate full-diff API; allowing a second tab for a draining path. |
| 2026-10-29 | D21 | Inject `SessionManager` into `App` and keep the Phase 2 app entry point fake-backed with an app-local deterministic `DemoGitBackend`/`DemoWatcher`; add `UiTestTags` for stable UI tests and keep all visual constants in `GraphStyle.kt`. | Allows deterministic Compose tests without real Git, keeps Phase 2 isolated from Phase 3 integration, and supports the no-magic-numbers rule. | Wire `CliGitBackend`/real watcher now; use text-only selectors. |
| 2026-10-29 | D22 | Add the approved Compose UI test support (`org.jetbrains.compose.ui:ui-test` and `ui-test-junit4`, version 1.12.2) plus `testFixtures(project(":core"))` to `app` tests; QA generates smoke-test screenshots into `app/build/screenshots/`. | Enables fake-backed Compose smoke tests and visual evidence without adding an unapproved test framework. | No UI smoke tests or external screenshot tooling. |
| 2026-10-29 | D23 | Normalize porcelain-v2 `'.'` status sides to `' '` in `GitParsers.parseStatus`, so `StatusEntry` uniformly uses `' '` for unchanged. | Real Git reports unchanged sides as `.`, while session/UI guards expect `' '`; normalization prevents unstaged files being counted as staged. | Normalize separately in every consumer. |
| 2026-10-29 | D24 | Use index-only `git rm --cached -f -- <path>` for staged additions and unborn-HEAD removal. This deviates from the `git rm --cached --` text in `03-git.md`, but never changes the work tree. | Git’s safety check rejects `--cached` when staged content differs from HEAD and the work tree; `-f` is required for correct discard/unstage semantics. | Leave the plain command and accept partial failures. |
| 2026-10-29 | D25 | Phase 3 production uses `SessionManager` defaults (`CliGitBackend`, `JdkRepoWatcher`, `JsonSessionPersistence`); `Main.kt` opens a real repository and accepts an optional startup path. `DemoBackend`/`DemoWatcher` were removed from production. | Fakes must remain test-only; the app now exercises the real backend/watcher and real repository flow. | Keep the demo backend in production. |
| 2026-10-29 | D26 | Harden `GitRunner` with concurrent stdin/stdout/stderr draining, bounded shutdown and descendant cleanup, cleared repository-selection environment variables; watcher `OVERFLOW` emits `REFS_CHANGED` and failed starts/stops release resources. | Prevents deadlocks, inherited-environment redirection, leaked processes/threads, and missed refreshes without changing public contracts. | Keep the previous sequential runner/watcher behavior. |
| 2026-10-29 | D27 | Resolve `gitDirs` with one `git rev-parse` invocation per value instead of parsing the combined three-value output. | A work-tree path containing a newline makes the combined output ambiguous; per-value resolution is correct and still uses `rev-parse`. This deviates from the combined command text in `03-git.md`. | Keep line-based parsing and reject newline paths. |
| 2026-10-29 | D28 | Harden diff UX: cap displayed diff lines at `GraphStyle.MAX_DIFF_LINE_CHARS` without changing model text, scope discard confirmation to the active session/tab, and refresh status after a failed diff. | Matches docs/11 and prevents cross-tab discard accidents/stale panels. | Leave long-line layout and stale status behavior unchanged. |
| 2026-10-29 | D29 | Accept the first-visible-rows performance deviation: **713 ms vs the 400 ms target** on the 200k repo. All other docs/09 budgets pass (full graph 817 ms, overhead −0.2%, layout 2.66M/4.96M rows/s, memory 206/260/329 B/commit, scroll max 0.23 ms, tab switch p99 0.02 ms, status overhead 1.67 ms). | Measurement attributes the miss to raw `git log --topo-order` (594 ms for the first 2,000 rows); FreeTree adds little overhead. A commit-graph lowers cold first rows to 142 ms and is documented as the mitigation. No measured graph/query bottleneck justified a rewrite. | Two-phase first paint or automatic commit-graph writes (out of scope/never automatic). |
| 2026-10-29 | D30 | Ship the macOS Dmg unsigned/unnotarized, keep Deb/Msi host-specific, and use the provided `temp/FreeTreeIcon.icns` copied to `app/icons/FreeTree.icns` for the macOS bundle. | Host packaging is the documented constraint; the icon was supplied by the user and the built bundle embeds it byte-for-byte. | No custom icon or cross-compiled installers. |
| 2026-10-30 | D31 | Post-MVP UI polish: add one shared `ModernScrollbar` component; keep the history scrollbar permanently visible and panel scrollbars transient; preserve the viewport on commit clicks while letting keyboard navigation reveal rows; round the tab/plus highlights and center the plus with a Canvas. | Implements the requested navigation/visual fixes with shared code and no new dependencies or contracts. | Per-screen scrollbar implementations; selection auto-scroll; font-glyph plus. |
